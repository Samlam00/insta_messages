# Insta Messages

Instagram for followed accounts — feed, stories, and DMs. No explore, reels, or profiles.

## Features

- View your Instagram feed from followed accounts only
- Browse stories from accounts you follow
- Send and receive direct messages
- Chronological feed (no algorithmic feed)
- Lightweight Electron wrapper around Instagram web

## Installation

Download the latest release from [Releases](https://github.com/Samlam00/insta_messages/releases/tag/v1.0.0), extract the zip, and run `Insta Messages.exe`.

## Running from source

```bash
npm install
npm start
```

## Building

```bash
npm install --save-dev electron-builder
npm run build
```

This creates a distributable zip file in `dist/`.
